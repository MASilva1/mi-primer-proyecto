## Proyecto destacado

### [Sala 13 — Sistema de reservas y automatización administrativa](sala13-reservas-inteligentes/README.md)

**Desafío:** consultas repetitivas de disponibilidad, superposiciones y coordinación manual de una sala compartida.  
**Intervención:** análisis del proceso, diseño funcional y desarrollo de una Web App de reservas con JavaScript, HTML, CSS, Apps Script y FullCalendar.  
**Integraciones:** Google Calendar, Sheets y correo electrónico.  
**Resultado reportado:** ahorro operativo estimado del 80 % en la tarea de coordinación durante el uso inicial; estimación no auditada.  
**Habilidades:** automatización administrativa, business analysis, desarrollo web, integraciones, mejora continua, programación asistida por IA y supervisión humana.
